# Multi-Event & Wedding Planning Portal

A comprehensive, production-ready web application designed to help users plan and organize weddings, birthdays, anniversaries, and corporate events with precision. Built with a modern **MERN stack** (MongoDB, Express.js, React, Node.js) and styled with **Tailwind CSS**.

## ✨ Key Features

* **Multi-Event Management:** Support for managing multiple event types (Weddings, Birthdays, Anniversaries, Corporate Events) under a single user account with seamless switching and event deletion.
* **Step-by-Step Planning Wizard:** Structured layout guiding users through Couple/Host Details, Event Information, Guest Lists, Budgets, Timelines, and Seating Maps.
* **Robust Budget Tracking:** Detailed default categories (Plate Costs, Reception Hall, Photography, Beauty Salon, Honeymoon, etc.) with real-time calculations for Total Budget, Remaining Payments, and Unpaid Items.
* **Guest & RSVP Management:** Track adult and child headcounts, side allocation (e.g., Bride's vs Groom's sides), and RSVP statuses.
* **Contacts & Timeline Management:** Inline CRUD management for vendor and important contacts, alongside a complete schedule/timeline coordinator layout.
* **Secure Authentication:** JWT-based user authentication with encrypted passwords via bcrypt.

## 🛠️ Tech Stack

* **Frontend:** React, Tailwind CSS, Lucide Icons, React Hot Toast
* **Backend:** Node.js, Express.js, Mongoose, JSON Web Tokens (JWT), bcryptjs
* **Database:** MongoDB
